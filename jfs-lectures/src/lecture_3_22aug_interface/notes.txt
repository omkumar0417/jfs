introduction
an interface in java is a blueprint of a class that contains behavior (methods) but generally does not contain implementation .
an interface tells a class: these are the methods you must implement .
it also support multiple inheritance in java.
a class must implement all abstract methods of an interface.
all variables in an interface are public static and final by default
interface can have default static and private methods.
